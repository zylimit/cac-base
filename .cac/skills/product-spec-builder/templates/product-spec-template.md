# Product Spec 输出模板

文件名：`Product-Spec.md`（放项目根目录）。
- 每条功能需求必须带来源标记：`[确认]`（用户确认，附案例编号或原话）、`[推断]`（AI 推断，附依据）、`[默认]`（低风险默认做法，附依据，用户可否决）。
- `[待定]` **全文只许出现在「待定问题」表**，功能需求列表严禁挂 `[待定]`；未决问题在功能需求中先写成保守 `[默认]` 做法，同时在「待定问题」表五格填齐。
- 11 个必需二级段名（`predev-lint.mjs` 机器检查，不可删改）：`产品概述` / `应用场景` / `成功判据` / `范围与非目标` / `功能需求` / `规则与例外` / `关键流程` / `决策依据` / `技术方向` / `待定问题` / `澄清记录`。
- 生成时必须把所有 `{{...}}` 与 `<...>` 模板槽替换为真实项目内容，严禁残留占位符！

---
