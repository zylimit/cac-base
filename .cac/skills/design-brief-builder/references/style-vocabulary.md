[典型风格词汇与适用边界]
    | 风格方向 | 核心特征 | 适用场景 | 慎用场景 |
    |---|---|---|---|
    | **瑞士极简网格** | 严格对齐、克制字重、留白分明、细线分割 | 文档、专业案头工具、品牌页 | 强引导型新手消费端 |
    | **高密度数据工作台** | 紧凑行高、`tabular-nums`、状态点、面板不挤压主区 | 运维监控、调度台、B 端后台、金融 | 移动端低频轻交互 |
    | **暖纸编辑风** | 温润浅底、高对比墨色、零阴影明度分层 | 审校、知识库、阅读写作 | 多维实时告警大屏 |
    | **深色工程台** | `#121212` 起深灰底（禁刺眼纯黑）、白色透明度叠层 | IDE、音视频剪辑、长时暗光盯屏 | 户外强光手持作业端 |
    | **终端 CLI / TUI** | 等宽字体、语义色 + 符号冗余、80 列优雅降级 | 命令行工具、编码 Agent | 普通大众消费端 |

[五类 AI 生成界面通病（未在 Brief 显式指定时一律禁用！）]
    1. **紫靛默认主色**：主按钮与品牌色无脑落入 `#6366f1` / `#8b5cf6` 紫靛色带（`ui-slop-scan.mjs` 直接报 error）。
    2. **奶油底 + 衬线大字 + 陶土橙套餐**：`#F4F1EA` 配 `#D97757` 的千篇一律模板感。
    3. **SaaS 浮卡综合征**：任何内容都包一层 `border-radius: 16px` + 灰阴影卡片、卡中套卡、渐变色标超过 3 个。
    4. **机器套话装饰**：每个标题顶一条字距拉开的 ALL-CAPS 小眉标；元信息全用 `A · B · C` 中点拼接；按钮文案末尾全塞 `→`。
    5. **排版与动效失控**：正文字号 <14px、小字号设负字距、正文行高脱离 `1.4–1.6`、每滚一段就淡入上滑、引入外部 Google Fonts CDN 拖慢或破坏离线打开。
